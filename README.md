# Aravind Financial Website — Full Stack Starter

## Stack
Next.js + Supabase/PostgreSQL + Vercel/GitHub.

## Local setup
1. Install Node.js 20+.
2. Run `npm install`.
3. Create a Supabase project.
4. Run `supabase/schema.sql` in Supabase SQL Editor.
5. Copy `.env.example` to `.env.local` and add your Supabase URL, anon key, service-role key and a strong ADMIN_EMAIL value (used as the current simple admin key).
6. Run `npm run dev`.
7. Open http://localhost:3000.

## Admin
Open `/admin` and enter the ADMIN_EMAIL environment value. This is a starter gate, not production-grade authentication. Before public launch, replace it with Supabase Auth.
